{# Leaflet, and the muted base map drawn under it. Pinned versions with integrity hashes computed from the files the CDNs serve. If a CDN ever served something else, the browser refuses to run it. The base map is OpenFreeMap's Positron style - mostly white and grey, so the pins carry the colour. It is vector tiles, drawn by MapLibre GL and placed inside Leaflet by maplibre-gl-leaflet. No key and no account. MapLibre is pinned to 5.x because 6.x ships only as an ES module, which the Leaflet bridge cannot load from a plain script tag; the bridge itself is not on cdnjs, so it comes from jsdelivr. If any of it fails to load, or the browser has no WebGL, common.js falls back to OpenStreetMap's own tiles, greyed out. #}
