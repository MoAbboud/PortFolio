# Breakdown Takes - Overview

Public document. Behaviour only.

## What this is

A visual aid for narrating a story. You describe a story as a set of beats, each labelled
with the part it plays - setup, escalation, conflict, action, reaction, verdict - and the
tool draws them as a tree that reveals itself one beat at a time, at a pace you set.

It is built to be screen-recorded. You press play, narrate over it, and the growing tree
becomes the visual layer of a short video.

## The problem it addresses

Narrated story videos need something on screen, and the usual answers are stock footage or
a wall of text. Neither shows the structure of the story. A tree that grows as the story
is told does, and it does it in time with the narration rather than ahead of it.

## What it does

| Capability | Description |
| --- | --- |
| Take a story | Paste a story described as a title, a source, an author, a verdict, and a list of beats |
| Lay it out | Beats are positioned automatically from how they connect. Nothing is dragged by hand |
| Colour by role | Each beat is coloured by the part it plays, with a legend |
| Reveal in time | Beats appear one at a time at a chosen pace |
| Control playback | Play, pause, step forward one beat, and reset |
| Show the whole thing | Reveal every beat at once, to check the layout before recording |
| Track what was made | Append a row about the story to a spreadsheet file |

## The six roles a beat can play

| Role | What it marks |
| --- | --- |
| Context | The setup. Who, where, what the arrangement was |
| Escalation | Something changes and raises the stakes |
| Conflict | The actual disagreement |
| Action | Somebody does something about it |
| Reaction | How the others responded |
| Verdict | The conclusion |

The list is fixed and short on purpose. It is a story grammar, and a beat that fits none of
the six is usually two beats.

## How to use it

1. Open the page.
2. Write the story as a list of beats. Each beat has an identifier, its text, its role, and
   which earlier beat it follows. A worked example is loaded when the page opens.
3. Generate. If the description has a mistake in it, the tool says so before drawing
   anything.
4. Check the layout with everything revealed.
5. Reset, choose a pace, and start your screen recorder.
6. Press play and narrate each beat as it appears.
7. Save a tracking row so you have a record of what was made.
8. Take the recording into whatever you edit video in.

## What it does not do

- It does not write stories. You supply every word.
- It does not record. Use a screen recorder; the tool is the thing on screen, not the
  capture.
- It does not produce audio, subtitles or a finished video.
- It does not fetch stories from anywhere. Nothing is scraped and nothing is linked.
- It does not save your stories. Only the tracking row leaves the page.
- It does not let you drag beats around. The layout is computed and that is the whole point.

## Requirements to run it

A browser. Nothing to install, no account, no server, no connection needed. Appending
directly to a spreadsheet file needs a browser that supports writing to a file you have
picked; where that is unavailable, the row downloads instead.
