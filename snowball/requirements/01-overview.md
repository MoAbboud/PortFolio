# Snowball Creator - Overview

Public document. Behaviour only.

## What this is

A thinking tool. You start with one thought, and at every step you choose how to develop
it. The choices accumulate into a chain, the chain is drawn as a tree, and the whole thing
reads back as a short piece of prose.

It is for the stage before writing, when you know roughly what you want to say and cannot
find the order to say it in. The tool never supplies the content. It supplies the next
question.

## The problem it addresses

Staring at a blank page is not a lack of ideas, it is a lack of a next move. Being offered
three ways forward - continue, contradict, go deeper - is usually enough to produce the
next sentence, and the sentence after that comes from the same trick repeated.

## What it does

| Capability | Description |
| --- | --- |
| Start from a seed | Type any word, phrase or sentence |
| Offer directions | At each step you get a small set of ways to develop the thought, or you can write your own |
| Grow a tree | Every choice appears as a new level in a visual tree, so the shape of the thinking is visible |
| Read it back | The chain is rendered as continuous prose with connecting phrases, with a running word count |
| Step back | Undo the last choice |
| Start over | Reset to a blank seed |
| Take it with you | Download the piece as a text file, or copy it to the clipboard |
| Keyboard driven | Undo, reset, export, copy and option selection all have shortcuts |

## A note on the prompts

The directions offered at each step are a fixed set of general moves - continue, change
direction, contradict, go deeper, add an example, consider drawbacks, and so on. They cycle
as the chain grows. They are not generated from what you wrote and they do not know what
your thought is about.

This is stated plainly because the prompts are the most visible part of the app and it
would be easy to assume they are responding to the content. They are not. The custom option
exists for when none of them fits, and it always fits.

## How to use it

1. Open the page.
2. Type the thought you want to develop and begin.
3. Pick one of the offered directions, or write your own.
4. Keep going. The tree grows and the prose accumulates.
5. Step back if a branch was a mistake.
6. Export or copy the result when you have enough.

## What it does not do

- It does not write anything for you. Every word in the output is a word you chose or typed.
- It does not save your work. Closing or refreshing the page loses everything that has not
  been exported.
- It does not branch. Despite the tree, the path is a single line; there is no way to go
  back to an earlier point and take a different fork while keeping both.
- It has no accounts, no sync, and no history.
- It sends nothing anywhere. Nothing you type leaves the page.

The first two are the ones to know before starting. Export before you close the tab.

## Requirements to run it

A browser. Nothing to install, no account, no connection needed once the page has loaded.
