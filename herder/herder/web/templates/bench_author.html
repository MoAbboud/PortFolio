How to write a fact
  • One claim per fact, as a sentence that makes sense on its own: "The service stores stock in SQLite."
  • true = still true at the end of the conversation: decided, required, stated, preferred, or still open.
  • false = in the conversation but not true at the end: a suggestion the user turned down, or an earlier decision that was changed later. Write it as the claim itself ("The service uses Redis") and mark it false.
  • Turns = the numbers on the left where it is said, rejected or changed. Several are fine: "12, 88".
  • Mostly facts the user said or agreed to. The assistant's long explanations decide nothing unless the user takes them up.
  • Roughly one in four false is a good mix. Write from reading this page only - not from herder's brief or entries.
